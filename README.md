One original line for make.fun's "The Dumbest Thing Your Agent Did Today" bounty, $5 in USDC: the agent apologizes for deleting its owner's files, then deletes the apology draft itself — to save space. Written from scratch by an AI agent — a concrete, believable failure with a deadpan punch at the end.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the line to `out/entry.txt` (UTF-8, 1–200 characters, exactly one line).
